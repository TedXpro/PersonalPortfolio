## 💼 Flagship Projects

### 🏦 [BirrWise — AI-Powered Multi-Currency Financial Platform](https://birrwise.com)
> **Production Financial Ledger & Intelligent Expense Analytics**

- **Receipt OCR Engine**: Automatic camera/image extraction of merchants, dates, itemized breakdowns, taxes, and totals directly into ledger records.
- **RAG Conversational Assistant**: Interactive AI assistant querying user financial histories with semantic retrieval (**pgvector** + **LangChain**).
- **Autonomous n8n Automations**: Event-driven transaction classification, budget threshold notifications, and recurring ledger synchronizations.
- **Stack**: `Next.js` · `TypeScript` · `Supabase (pgvector)` · `LangChain` · `OCR` · `n8n` · `Tailwind CSS`
- 🔗 **Live**: [birrwise.com](https://birrwise.com)

---

### 🌾 [Agricultural Crop Yield Prediction Pipeline](https://github.com/TedXpro/MachineLearning)
> **Ensemble Regression ML Models for Agricultural Planning**

- **Predictive Modeling**: Ensemble regression pipeline (Random Forest, Gradient Boosting, XGBoost) forecasting regional harvest yields with **R² = 0.89**.
- **Technical Report**: Full technical write-up with EDA, feature engineering, model comparison, and cross-validation analysis.
- **LSTM Modeling**: Deep learning time-series experiments for sequential crop data prediction.
- **Stack**: `Python` · `Scikit-Learn` · `Pandas` · `NumPy` · `Matplotlib` · `Jupyter`

---

### 🆘 Disaster Event NLP Classifier

- **Stack**: `PyTorch` · `Hugging Face Transformers` · `Scikit-Learn` · `NLTK`
